# Yandex Disk API Tests

Автотесты для REST API Яндекс.Диска.

Проект проверяет основные операции с папками через HTTP-методы PUT, GET, POST и DELETE, а также несколько позитивных и негативных сценариев.

## Стек

- Python 3
- Pytest
- requests
- python-dotenv

## Что проверяется

### PUT

- создание новой папки;
- запрос без обязательного `path`;
- попытка создать уже существующую папку.

### GET

- получение существующей папки;
- получение выбранных полей через `fields`;
- запрос без `path`;
- получение несуществующего ресурса;
- запрос без OAuth-токена.

### POST

- копирование существующей папки;
- копирование несуществующего ресурса;
- копирование в уже существующий путь без `overwrite`;
- асинхронное копирование с `force_async=true`.

### DELETE

- окончательное удаление существующей папки;
- удаление несуществующего ресурса.

Всего реализовано 14 автотестов.

Более подробный список сценариев находится в `TEST_PLAN.md`.

## Асинхронные операции

При использовании `force_async=true` API может вернуть `202 Accepted` и ссылку на операцию.

В этом случае тест периодически запрашивает состояние операции до получения `success`.

Ожидание ограничено по времени, чтобы тест не выполнялся бесконечно.

## Тестовые данные

Для тестовых папок используются уникальные имена на основе UUID.

Это позволяет запускать тесты несколько раз и уменьшает вероятность конфликтов между тестовыми данными.

Созданные во время тестов ресурсы удаляются после выполнения проверок.
