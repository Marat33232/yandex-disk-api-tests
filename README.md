# Yandex Disk API Tests

Учебный проект с автотестами REST API Яндекс.Диска.

## Стек

- Python 3
- Pytest
- requests

## Что проверяется

Основные операции с ресурсами Яндекс.Диска:

- создание папок;
- получение информации о ресурсах;
- копирование;
- удаление;
- основные негативные сценарии;
- асинхронные операции.

Подробные сценарии находятся в `TEST_PLAN.md`.

## Безопасность

OAuth-токен хранится локально в `.env` и не добавляется в Git.
